# Archive

Historical artifacts, preserved for the record and no longer part of the active project surface.

## `kaggle-submission/`

MCP-Tripwire was originally prototyped as a submission to the **Google 5-Day AI Agents Intensive** (Kaggle Freestyle track), June 2026. These are the submission-specific artifacts from that effort:

- [`writeup.md`](kaggle-submission/writeup.md) — the ≤2,500-word competition writeup.
- [`video-script.md`](kaggle-submission/video-script.md) — the five-minute demo video script.
- [`SUBMISSION_CHECKLIST.md`](kaggle-submission/SUBMISSION_CHECKLIST.md) — the pre-submission verification checklist.
- [`SPRINT-2026-06-27-to-2026-07-05.md`](kaggle-submission/SPRINT-2026-06-27-to-2026-07-05.md) — the delivery sprint plan for the submission window.

The competition was where the project started; it is not what the project is. MCP-Tripwire is now a real open-source **trust gateway for MCP tools**, developed toward production usefulness. For the current project, start at the [root README](../../README.md), the [product spec](../SPEC.md), and the [roadmap](../ROADMAP.md).
